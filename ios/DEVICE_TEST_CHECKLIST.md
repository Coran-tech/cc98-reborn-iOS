# iPhone 16 Pro 真机验证

目标设备：iPhone 16 Pro，iOS 26.5.2。App 最低支持 iOS 17。云端模拟器只验证容器与脱敏测试场景，下列项目必须在真机分别记录结果。

用户已反馈 Build 8 安装成功、功能正常。该反馈未逐项记录以下测试；0.2.0 新增的 OpenID 授权需要单独验证。

## 安装候选包

1. 从本次成功的 GitHub Actions 构建下载 artifact。完整云端验证包为 `CC98RebornShell-unsigned-device.ipa`；优先真机试装包为 `CC98RebornShell-unsigned-unverified-device.ipa`，后者保留 Node、原生 OAuth 协议、设备编译、资源与包结构检查，未完成模拟器验证。两者都需要自行签名；不使用 Simulator `.app` 或其他来源的重新打包文件。
2. 按 [AltStore Windows 官方步骤](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows) 配置 AltServer、所需 Apple 组件和 iPhone 信任关系。Apple Account 与双重认证由你自行输入，不发到聊天或云构建。
3. 在 iPhone 开启“设置 → 隐私与安全性 → 开发者模式”，按系统要求重启和确认。通过 AltStore 导入候选 IPA 并签名安装。
4. 免费个人签名通常 7 天到期，安排续签；不依赖自动后台续签一定成功。首次验证同时确认你的 iOS 版本与当前签名工具兼容。升级重签尽量保留同一 App 身份，不先卸载含有草稿的版本。

## 验证顺序

| 项目 | 操作 | 通过条件 | 状态 |
| --- | --- | --- | --- |
| 原站可达 | 校内 Wi-Fi 或已连接、覆盖本 App 的系统 VPN 下启动 | 页面是原站 HTTPS 内容；无代理登录页；错误有可操作的恢复入口 | 待真机 |
| 官方登录 | 在原站模式登录，退出 App 后重新打开，再测试原站退出 | 会话按原站规则恢复/退出；密码和 token 不进入诊断内容 | 待真机 |
| 本地注入 | 切到 Reborn 模式，查看启动诊断和页面表现 | 脚本和样式按资源版本启动，无重复界面；资源加载失败可识别 | 待真机 |
| 同账号绑定 | 点击“绑定同一账号”，在系统窗口授权 | 回到 App 后 UID 一致、水印正确、绑定提示消失；未提交内容不被重载 | 新版待真机 |
| 取消与错账号 | 先取消一次，再用另一账号授权，最后用正确账号重试 | 取消和错账号不产生绑定；错误明确，正确账号可重试成功 | 新版待真机 |
| 绑定持久化与解绑 | 成功绑定后重启 App，再解除本地绑定 | 摘要可恢复；解绑后重新出现绑定提示，论坛登录仍在 | 新版待真机 |

| 编辑不丢字 | 在获准测试位置输入中文，移动选区、粘贴、撤销、收起键盘 | 输入法组合不被重建打断；工具栏、选区和输入内容可用 | 待真机 |
| 文件选择和上传 | 在原站模式使用一张不敏感测试图片；先取消一次，再实际上传一次 | 取消可恢复；成功只上传一次；预览和原站校验结果正确 | 待真机 |
| 提交结果 | 仅在你有权使用的测试场所提交一次内容，或只验证原站表单校验 | 不重复发帖；校验/网络失败保留编辑内容；未知结果先核对，不盲目重发 | 待真机 |
| 原站恢复 | 有未发草稿时触发模式切换，先取消，再确认切回原站 | 取消不丢内容；确认时清楚提示重载风险；原站重新加载后登录仍在 | 待真机 |
| 断网恢复 | 断开 VPN 或切换网络，再恢复后手动重试 | 不把网络错误当退出；原站恢复可用；不自动重发上传/发帖 | 待真机 |
| 更新续签 | 保留少量测试设置后续签同一 App | 能再次打开；确认哪些设置/会话保留，不承诺跨 Bundle ID 自动迁移 | 待真机 |

OpenID 回调 `org.cc98.reborn.shell:/oauth/callback` 已由用户确认保存。先完成同账号绑定，再验证增强阅读、编辑和水印；“脚本已注入”不能代替绑定验收。详细配置见 [OpenID 配置与验收](https://github.com/Coran-tech/cc98-reborn-iOS/blob/codex/ios-verification-shell/ios/OPENID_PREREQUISITES.md)。

## 回传结果

每项记录：构建编号、模式、网络类型、操作、预期与实际结果。可以提供裁去账号资料和正文的截图，以及壳内脱敏诊断。不要提供密码、验证码、Cookie、Authorization、OAuth 回调 query 或真实私信。

如果使用 `unverified` 试装包，先验证启动和原站可达，再验证本版授权及编辑上传。系统授权窗口、原生令牌请求和论坛 WebView 都需要被当前校网或系统 VPN 覆盖。

如果重载可能丢失未提交内容，先取消操作并手动复制保存草稿。不要为排错先清空网站数据或卸载 App。
